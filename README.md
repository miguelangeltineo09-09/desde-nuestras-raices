# Desde Nuestras Raíces

Sitio web de la fundación comunitaria **Desde Nuestras Raíces**, dedicada al bienestar de las comunidades vulnerables de Baní.

## Stack

- [Astro](https://astro.build)
- [Tailwind CSS](https://tailwindcss.com)

## Desarrollo local

```sh
npm install && npm run dev
```

El sitio queda disponible en `http://localhost:4321`.

## Notas

Este es un sitio 100% estático, sin backend ni base de datos. Se despliega en Vercel.
